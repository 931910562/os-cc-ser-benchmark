01 / THE BENCHMARK

Shared classes. An open target space.

Evaluate known-class recognition and unknown-class rejection together. Corpus shift and novel emotions can produce similar feature deviations, so adaptation must select which target samples to align.

A common task definition

The source domain uses only happy, sad and angry labels. The target domain retains all emotions; non-shared classes are grouped as unknown for open-set evaluation. Target labels are reserved for final evaluation.

happy · 0sad · 1angry · 2

Released arrays retain the full emotion indices: neutral=3, surprise=4, fear=5 and disgust=6. Unknown classes are merged at evaluation time.

Reproducibility audit: labels, sample counts and model selection

ResNet processing is deferred and its packages are excluded from this release. The other four representations use happy=0, sad=1, angry=2, neutral=3, surprise=4, fear=5 and disgust=6.

ESD has 17,500 ResNet samples and 35,000 samples for the other representations. MSP has 14,799 ResNet samples and 15,730 for the others. WavLM contains 12,921 MELD samples, compared with 12,923 elsewhere. Matching coverage across representations cannot be claimed without complete sample identifiers.

Some original training entries select checkpoints using target HOS, which conflicts with the paper's final-evaluation-only constraint. A strict rerun must first resolve model-selection and data-split issues. This release preserves the supplied behavior; paper results do not establish a completed rerun.
