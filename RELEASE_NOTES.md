Nine supplied methods, the manuscript's 540 appendix configurations, a responsive project page, file provenance, and four active feature packages: eGeMAPS, wav2vec 2.0, WavLM and HuBERT.

ResNet preparation and both ResNet feature archives are on hold at the author's request and are excluded from this upload. Original archives and previously prepared local files remain preserved.

Feature files are supplied artifacts. No full training rerun is claimed. Please read REPRODUCIBILITY.md before claiming uniform sample coverage or strict label-free target checkpoint selection.
